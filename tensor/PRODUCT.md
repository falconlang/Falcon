# Product

## Register

product

## Users

Mixed audience: beginners learning App Inventor and Falcon for the first time, alongside experienced developers using Tensor as a focused coding environment. A student building their first calculator app shares the same tool with a developer managing a full event-handler library. The interface cannot condescend to beginners or frustrate power users.

## Product Purpose

Tensor is a notebook IDE for the Falcon language, an event-driven DSL for MIT App Inventor projects. Users write code in cells, compose a design DSL in the right pane, and send live updates to an Android device via the Companion connection (WebRTC). Success looks like: code written, tested on phone, iterated fast.

## Brand Personality

Capable colleague. Sharp but not cold. Notebook-native: the environment feels like a well-made notebook, not an enterprise dashboard or a game. Personality reference: Google Colab's clean, paper-like quality, adapted to a distinct green-accented identity.

## Anti-references

Heavy dark-gamer aesthetic (neon on black, aggressive shadows). Toy-like or childish (overly bright, playful). Generic SaaS dashboard (rounded card grids, gradient hero metrics). VS Code clone (a recolored editor without its own visual character).

## Design Principles

1. The notebook is the primary surface: cells should feel like clean, focused documents.
2. Chrome recedes: every toolbar element, border, and decoration must earn its presence.
3. Dual audience coherence: the interface reveals depth to experienced users without overwhelming beginners.
4. Legibility over compression: code is meant to be read; preserve whitespace rather than trading it for density.
5. State is always surfaced: errors, connection status, and cursor position are never hidden.

## Accessibility & Inclusion

WCAG AA minimum. Reduced motion supported. All interactive elements reachable via keyboard.
