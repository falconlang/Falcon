=== ENTRY 201 ===
Goal: Count all valid ways to place N queens on an N×N board so none attack each other.

1. We use a helper function solve(row, n, cols, diag1, diag2):
   - row = the current row we are trying to place a queen in
   - n = the board size
   - cols = list of columns already occupied by queens
   - diag1 = list of (row - col) values already used — tracks one diagonal direction
   - diag2 = list of (row + col) values already used — tracks the other diagonal direction

2. Base case: if row > n, all n queens have been placed successfully, so return 1 (found one solution).

3. Otherwise, try every column c from 1 to n in the current row:
   - Check: is column c already in cols? If yes, skip — another queen is in that column.
   - Check: is (row - c) already in diag1? If yes, skip — diagonal conflict.
   - Check: is (row + c) already in diag2? If yes, skip — other diagonal conflict.

4. If all three checks pass:
   - Add c to cols, (row - c) to diag1, (row + c) to diag2 — mark this queen's position.
   - Recursively call solve(row + 1, ...) and add the returned count to a running total.
   - Then REMOVE the last element from cols, diag1, diag2 — this is backtracking, undoing the move so we can try the next column.

5. After trying all columns, return the total count.

6. nQueens(n) simply calls solve(1, n, [], [], []) — start from row 1 with empty tracking lists.

7. println(nQueens(4)) prints 2, meaning there are exactly 2 solutions for a 4×4 board.
